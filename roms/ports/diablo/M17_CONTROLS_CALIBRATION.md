# M17 Diablo 1 (DevilutionX) Full Controls & Config Reference (v44)

## 📌 Повна конфігурація: Ізометричний біг + Віртуальна миша (v44)

У версії **v44** об'єднано дві системи введення для максимальної зручності:
1. **Аналоговий стік**: для ідеального 8-позиційного бігу персонажа по підземеллю.
2. **D-Pad (Хрестовина)**: для керування віртуальним курсором миші (рукою/стрілкою) в інвентарі, меню та виборі заклинань.
3. **Кнопка A**: вибір/захоплення предмета та вставляння в слот екіпірування (`BTN_LEFT`).
4. **Кнопка X**: швидке використання предмета (`BTN_RIGHT`, випити зілля, вивчити книгу).
5. **Кнопка Y**: каст заклинань під час бою.

---

### 1. Керування стіком (ходьба в підземеллі):
* ➡️ **Стік Вправо (3:00)** ➔ правий верхній коридор (**1:30**) ✅
* ⬆️ **Стік Вгору (12:00)** ➔ лівий верхній коридор (**10:30**) ✅
* ⬇️ **Стік Вниз (6:00)** ➔ правий нижній коридор (**4:30**) ✅
* ⬅️ **Стік Вліво (9:00)** ➔ лівий нижній коридор (**7:30**) ✅
* ↗️ **Вгору-Вправо (1:30)** ➔ прямо вгору на екрані (**12:00**) ✅
* ↘️ **Вниз-Вправо (4:30)** ➔ прямо вправо на екрані (**3:00**) ✅
* ↙️ **Вліво-Вниз (7:30)** ➔ прямо вниз на екрані (**6:00**) ✅
* ↖️ **Вліво-Вгору (10:30)** ➔ прямо вліво на екрані (**9:00**) ✅

---

### 2. Керування D-Pad (віртуальна миша для інвентаря та меню):
* ⬆️ **D-Pad Вгору** ➔ рух курсора вгору
* ⬇️ **D-Pad Вниз** ➔ рух курсора вниз
* ⬅️ **D-Pad Вліво** ➔ рух курсора вліво
* ➡️ **D-Pad Вправо** ➔ рух курсора вправо
* 🔘 **Кнопка A** ➔ **Лівий клік миші (Click / Pick up & Drop)**:
  - Навести курсор на меч/броню/шолом в інвентарі та натиснути **A** ➔ предмет береться в руку (захоплюється курсором).
  - Навести курсор на відповідну клітинку екіпірування зліва та натиснути **A** ➔ предмет вставляється в слот / одягається!
* 🔘 **Кнопка X** ➔ **Правий клік миші (Use)**:
  - Навести на зілля чи книгу та натиснути **X** ➔ предмет використовується / вивчається.

---

### 3. Бойова система та заклинання:
* ⚔️ **Кнопка A**: атака зброєю в руках / взаємодія з об'єктами.
* 🔮 **Кнопка Y**: каст вибраного заклинання (заклинання вибирається через меню сплів за допомогою D-Pad + A).
* 🧪 **Кнопка B / X**: використання предметів зі швидкого поясу.

---

### 4. Модифікація збереження (Безкінечна мана):
* **Персонаж**: Horazon (Sorcerer, Level 2)
* **Файл збереження**: `single_0.sv` (розташований у `roms/ports/diablo/single_0.sv`)
* **Резервна копія оригіналу**: `single_0.sv.bak` (збережена на карті)
* **Встановлені показники**:
  - `pManaBase` / `pMaxManaBase`: **50 000 / 50 000** (3 200 000 внутрішніх одиниць).
  - `pBaseMag`: **250** (максимальний інтелект для читання будь-яких книг).
